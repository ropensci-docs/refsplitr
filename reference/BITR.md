# Data from the journal Biotropica (pulled from Web of Knowledge)

A dataset containing 10 articles taken from the journal Biotropica. This
dataset represents the typical formatted output from
[`references_read()`](https://docs.ropensci.org/refsplitr/reference/references_read.md)
in the refsplitr package. It serves as a testbed for commonly
miscategorized names

## Usage

``` r
BITR
```

## Format

A data frame with 10 rows and 32 variables:

- filename:

  the original filename the text was created from

- refID:

  the unique identifier given to each reference article by
  references_read()

- AB:

  Abstract

- AF:

  Full Names

- AU:

  Abbreviated names

- C1:

  Addresses

- EM:

  emails

- RI:

  Web of Science ID

- OI:

  OrcID

- RP:

  Reprint Address

- TI:

  Title
